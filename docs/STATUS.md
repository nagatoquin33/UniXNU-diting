# Diting 实机状态（2026-11-20）

当前基线为 Redmi K50 至尊版（`diting` / SM8475 / Adreno 730）和 iPadOS 18.7.10（22H374）。本阶段收尾，后续计划评估 iOS 或 macOS 基线。

## 实机结果

| 项目 | 观察 |
| --- | --- |
| 启动 | `boot_a` 上的正式显示镜像已进桌面，八核启动。恢复槽 `boot_b` 保留 TWRP |
| 显示 | 面板 42_02_0a，1220×2712。切到 120 Hz 后，按每个 TE 自动刷新，117 个 DPU 采样窗口为 121.2–121.6 Hz。锁存平均 4.0–4.5 ms，最大 8.36 ms。应用合成最高采到 110 fps，仍有波动和可见残影 |
| 输入 | 普通触摸和 Safari 字母输入可用。Safari 和提醒事项出现键盘布局问题，地球键和 123 无法正常切换，设置里无法完成 Wi‑Fi 密码输入 |
| Wi‑Fi | 已实测可用 |
| Data | 实机窗口 228,197,380,096 B（212.53 GiB），APFS 容器 228,196,311,040 B，沿用卷 UUID。扩容副本比对了 5,962 个文件与链接，实机回读校验差异块、卷信息和偏好文件。OS、SystemOS 的全窗 SHA-256 与扩容前一致 |
| 其他 | 原生 USB 仍关闭，固件缺少真实 DMA 交接，系统缺 usb-mux 桥接和适配库。音量调节、视频解码、蓝牙仍有问题，休眠唤醒尚未验收 |

## 关键证据

- 旧镜像的自动刷新寄存器为 `0x8000003c`，DPU 每 60 个 TE 送一帧。正式镜像为 `0x80000001`，GPU fence 最大 3 µs，显示提交等待下降。
- 实际屏幕为 406.67×904 pt，Safari 记录到 375 pt 键盘视图。提醒事项照片也能看到键盘边缘裁切。UIKit 的键面回落与实际坐标偏差尚未追到具体调用点。
- userdata 尾部留 1 GiB，原有最后 4 MiB ramoops 区继续使用。更换 OS 基线前，保留现有 Data 备份与恢复镜像。
